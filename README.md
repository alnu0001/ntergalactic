# NTERGALACTIC

This repository is the static landing page for **ntergalactic.com**.

## Files

- `index.html` — page content
- `styles.css` — all visual design
- `script.js` — scroll progress and reveal motion
- `ntergalactic-logo.png` — official logo
- `CNAME` — custom domain for GitHub Pages
- `.nojekyll` — tells GitHub Pages to serve the static files directly

## Publish with GitHub Pages

1. Create a new GitHub repository. A simple name is `ntergalactic`.
2. Upload **all files in this folder to the root of the repository**.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. In **Settings → Pages → Custom domain**, enter:
   `ntergalactic.com`
7. Configure the DNS records at the company where the domain is registered.
8. After GitHub confirms DNS and provisions the certificate, enable **Enforce HTTPS**.

The site has no framework, build process, database, cookies, analytics, or third-party JavaScript. It can be hosted directly by GitHub Pages.
